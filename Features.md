# Platform Features

This document outlines all features of the Internship Management Platform, prioritized using the MoSCoW method (Must Have, Should Have, Could Have, Won't Have this time).

---

### Authentication
* **Must Have:**
  * User Registration and Login (Email/Password).
  * Role-based Access Control (Student, Recruiter, Admin).
  * Password recovery (Forgot password).
* **Should Have:**
  * Single Sign-On (SSO) with Google or College Email.
* **Could Have:**
  * Two-Factor Authentication (2FA) for Admin accounts.

### Student Features
* **Must Have:**
  * Digital Profile creation (Education, Skills, Experience).
  * Resume upload (PDF).
  * Internship search and filtering (by role, location, stipend).
  * One-click application process.
  * Application status tracking dashboard.
* **Should Have:**
  * Multiple resume versions.
  * Save/Bookmark internships for later.
* **Could Have:**
  * In-platform portfolio hosting or project showcase.
  * Skill assessment tests.

### Recruiter Features
* **Must Have:**
  * Company profile management.
  * Create, edit, and close internship postings.
  * Applicant Tracking System (ATS) Kanban board (Applied, Shortlisted, Interview, Offered).
  * Applicant filtering and sorting based on skills.
* **Should Have:**
  * Automated email triggers on application status change.
  * Interview scheduling integration.
* **Could Have:**
  * Collaborative hiring (multiple recruiter accounts per company).
  * Automated resume parsing (AI-based skill matching).

### Admin Features
* **Must Have:**
  * Dashboard for user management (Approve/Suspend accounts).
  * Oversight of all job postings to prevent spam.
  * Basic placement statistics (Total placed, total jobs).
* **Should Have:**
  * Broadcast announcement system.
  * Data export functionality (CSV/Excel).
* **Could Have:**
  * Custom reporting tools.

### Notifications
* **Must Have:**
  * In-app notifications for application status updates.
  * Email notifications for account verification and password reset.
* **Should Have:**
  * Email notifications for new messages or interview schedules.
* **Could Have:**
  * SMS or WhatsApp notifications for urgent updates.

### Reporting & Analytics
* **Must Have:**
  * Admin dashboard showing key metrics (Total users, active jobs, placement rate).
* **Should Have:**
  * Recruiter analytics (Views per job, applicant conversion rate).
* **Could Have:**
  * Student analytics (Profile views by recruiters).

---

## MoSCoW Prioritization Summary

**Must Have (MVP Foundation):**
* Core Authentication
* Student Profiles & Resume Upload
* Job Posting & Searching
* Application Submission & Status Tracking
* Basic Admin Oversight

**Should Have (Post-MVP Enhancements):**
* SSO Login
* Saved Jobs
* Automated Email Triggers
* Advanced Admin Export & Analytics

**Could Have (Future Roadmap):**
* AI Resume Parsing
* In-app Interviews / Assessments
* Multi-recruiter Collaboration
